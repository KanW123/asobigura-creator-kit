# ゲーム実装の確認項目

このキットは投稿ツールです。ゲーム内部を自動改修するものではありません。

- 音声: 非表示中はBGM/SEを消音・停止。表示復帰／次の操作で再開し、ミュート・音量を維持。音の溜め込み・二重再生を防ぎ、設定等へ手動復旧を用意。公開SDKに音声復旧ヘルパーはありません。別タブ・別アプリ・ロックと復帰を実機でも確認してください。
- セーブ: SDKのreadyを確認して既存のSaves APIを使用。フォールバックはクラウド保存成功ではありません。読込失敗を空データと見なして上書きしないでください。未送信データとアカウントを分離し、旧save_versionの読込を維持してください。SDKは自動同期や競合解決を行いません。
- 言語: PFはja/en/zh-CN/zh-TW/ko/es。iframeにはlangクエリを渡します。ゲーム内辞書・切替は作者側で実装します。top_levelへの自動引継ぎ、SDK言語取得APIはありません。ゲームIDやセーブキーを言語で変更しないでください。掲載文の翻訳はゲームZIP更新とは別のため運営への相談が必要です。
- 戻る: PF共通×/Escはありません。ゲーム内に戻る導線を用意し、操作起点で `platform.openUrl('https://asobigura.com/')` を使います。事前の保存・退出処理はゲーム側の責任。非同期保存後は再クリックで戻れるようにしてください。
- ランキング: スコア送信に加えてfeatures.leaderboardsの宣言が必要です。現在の投稿CLIからの宣言設定は未対応です。best/rating、カテゴリ、表示名を整理し運営へ相談してください。宣言なしではPFのランキングボタンは出ません。

実装仕様の正本: https://asobigura.com/sdk-reference.md 。独自のSDK APIを仮定しないでください。
